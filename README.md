# Бот-консультант по базе знаний

Telegram-бот, который отвечает на вопросы по структурированной базе знаний.
Ищет релевантные фрагменты в SQLite, передаёт их в LLM (DeepSeek) и формирует
короткий ответ. Если данных нет — фиксирует запрос и уведомляет владельца.

## Возможности

- **RAG-ответы:** в модель уходят только релевантные фрагменты базы (не вся БД).
- **DeepSeek** (`deepseek-v4-flash`) через OpenAI-совместимый API.
- Команды пользователя: `/start`, `/help` + свободный текстовый запрос.
- Кнопка **«Связаться с человеком»** — уведомление владельцу и контакты пользователю.
- Команды владельца: `/stats`, `/add`, `/list`.
- Память диалога: последние **20 сообщений** (вопросы и ответы) для уточнений.
- Guardrails против промпт-инъекций и утечки системного промпта.
- Конвертация Markdown → HTML для корректного отображения в Telegram.
- Импорт базы из Markdown (`scripts/import_md.py`) и демо-seed (`scripts/seed.py`).

## Стек

- Python 3.11+
- [aiogram 3](https://docs.aiogram.dev/) — Telegram Bot API
- SQLite через `aiosqlite`
- `openai` — клиент для DeepSeek / OpenAI-совместимого API
- `python-dotenv` — конфигурация через `.env`

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и заполните значения:

```
BOT_TOKEN=          # токен от @BotFather
OWNER_ID=           # числовой Telegram ID владельца
OWNER_CONTACT=      # например @username — для кнопки «Связаться с человеком»
DB_PATH=data/knowledge.db
LLM_API_KEY=        # ключ DeepSeek; если пусто — fallback без генерации
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-v4-flash
```

Telegram ID можно узнать у [@userinfobot](https://t.me/userinfobot).

## Наполнение базы знаний

```bash
# Из файла БАЗА_ЗНАНИЙ.md (если есть локально)
python -m scripts.import_md --reset

# Или демо-данные
python -m scripts.seed --reset
```

Также можно добавлять записи командой владельца:

```
/add ключевые слова | Заголовок | Текст ответа
```

## Запуск

```bash
python bot.py
```

## Команды и кнопки

| Действие | Кто | Описание |
|---|---|---|
| `/start` | пользователь | Приветствие и главное меню |
| `/help` | пользователь | Справка + список тем из базы |
| *текст* | пользователь | Вопрос по базе → RAG-ответ |
| «Связаться с человеком» | пользователь | Уведомление владельцу + контакты |
| `/stats` | владелец | Статистика запросов |
| `/add …` | владелец | Добавить запись в базу |
| `/list` | владелец | Список записей |

## Как обрабатывается вопрос

```
Запрос → поиск релевантных фрагментов
   ├─ профиль / услуги / прайс — свой набор разделов
   ├─ есть данные → LLM формирует короткий ответ
   └─ нет данных → фиксация + уведомление владельцу
```

Модель через API **не хранит** диалог сама: историю последних сообщений
передаёт бот при каждом запросе.

## Безопасность

- Секреты только в `.env` (в git не попадает).
- `*.db`, личная база знаний и дневник сборки исключены из репозитория.
- Guardrails: детектор инъекций, обёртка ввода, выходной фильтр утечек.
- Не публикуйте токен бота и ключ LLM.
