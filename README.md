# Бот-консультант по базе знаний

Telegram-бот, который отвечает на вопросы пользователей по структурированной
базе знаний. Ищет ответ в базе данных, а если не находит — подключает LLM
(DeepSeek), фиксирует запрос и уведомляет владельца.

## Возможности

- Поиск по базе знаний по ключевым словам и тексту.
- Команды пользователя: `/start`, `/help` + свободный текстовый запрос.
- Команды владельца: `/stats`, `/add`, `/list` (доступны только владельцу).
- Фиксация запросов без ответа и уведомление владельца.
- Учёт контекста диалога для уточняющих вопросов.
- Генерация ответов через DeepSeek (OpenAI-совместимый API) с безопасным
  fallback при отсутствии ключа или ошибке.

## Стек

- Python 3.11+
- [aiogram 3](https://docs.aiogram.dev/) — Telegram Bot API
- SQLite через `aiosqlite`
- `openai` — клиент для DeepSeek / OpenAI-совместимого API
- `python-dotenv` — конфигурация через `.env`

## Структура проекта

```
бот/
├── bot.py                  # точка входа: инициализация, polling
├── config.py               # загрузка настроек из .env
├── requirements.txt        # зависимости
├── .env.example            # шаблон переменных окружения
├── data/                   # файл базы данных SQLite (создаётся автоматически)
├── scripts/
│   └── seed.py             # наполнение базы демо-данными
└── app/
    ├── runtime.py          # разделяемые настройки времени выполнения
    ├── database/           # подключение к БД и запросы
    ├── handlers/           # хэндлеры пользователя и владельца
    ├── services/           # LLM (DeepSeek) и уведомления
    ├── keyboards/          # клавиатуры
    └── utils/              # логирование
```

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и заполните значения:

```
BOT_TOKEN=       # токен бота от @BotFather
OWNER_ID=        # ваш числовой Telegram ID
DB_PATH=data/knowledge.db
LLM_API_KEY=     # ключ DeepSeek (или OpenAI); если пусто — работает fallback
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
```

Свой Telegram ID можно узнать у бота [@userinfobot](https://t.me/userinfobot).

## Запуск

```bash
# (опционально) наполнить базу демо-данными
python -m scripts.seed

# запустить бота
python bot.py
```

## Команды бота

| Команда | Кто | Описание |
|---|---|---|
| `/start` | пользователь | Приветствие и главное меню |
| `/help` | пользователь | Справка |
| *текст* | пользователь | Поиск по базе знаний |
| `/stats` | владелец | Статистика запросов |
| `/add ключевые слова \| Заголовок \| Текст` | владелец | Добавить запись |
| `/list` | владелец | Список записей базы |

## Безопасность

- Секреты хранятся только в `.env` (исключён из git через `.gitignore`).
- Файл базы данных `*.db` также не попадает в репозиторий.
- Не публикуйте токен бота и ключ LLM в открытых репозиториях.
